# Zero to AI Engineer

A free, self-paced course from zero to AI engineering: 15 topics, 63 sub-topic videos,
in-browser coding exercises, quizzes, topic tests and PDF handouts.


## Folders
- `index.html` – the whole site
- `course.json` – lessons, exercises, quizzes and video timings
- `videos/` – lesson videos and posters
- `handouts/` – PDF handout for each topic
